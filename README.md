# Homework System

A web application to manage homework submissions for learners and teachers, including PDF uploads, MCQs, and dashboards for both teachers and students.

## Features

- Teacher and student dashboards
- Homework creation (PDF and MCQs)
- Real-time submissions and tracking
- Authentication for teachers and learners
- Event and mentorship pages
- Encldx content pages (extra features)

## Tech Stack

- Frontend: React, React Router, Context API
- Backend: Node.js, Express, TypeORM
- Database: MySQL
- Deployment: (Vercel / Railway / Heroku / etc.)
